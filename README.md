# Banking Fraud Analysis Using SQL

This project analyzes banking transaction data using SQL to identify fraud patterns and risk indicators.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Dataset
The dataset contains 10,000 banking transactions with transaction amount, payment channel, authentication type, device risk score, anomaly score, suspicious IP flag, and fraud flag.

## Analysis Questions
The SQL analysis includes:
- Total transactions
- Fraudulent vs non-fraudulent transactions
- Fraud percentage
- Fraud by payment channel
- Fraud by authentication type
- Card-present vs card-not-present fraud
- Anomaly score and fraud risk
- Suspicious IP fraud risk
- Top 10 riskiest transactions

## Files
- `data/`: Original dataset
- `sql/`: SQL analysis queries
- `report/`: Final project report

## Key Insight
Fraud risk varies across authentication methods, payment channels, card presence, suspicious IP status, and anomaly score levels.
